YouTube (livestream)

Badmintonapps adgang til YouTube. Den sættes op én gang for hele serveren — bagefter forbinder hver klub sin egen kanal under Livestream i klubbens admin. Indtil den er sat op, ser klubberne ikke YouTube-delen.

Hvor finder jeg Client ID og Client secret?
  1. Gå til console.cloud.google.com og log ind med Badmintonapps Google-konto. Vælg projektet Badmintonapp i projektvælgeren øverst. (Findes det ikke endnu: følg trin 1–5 og 7 i vejledningen docs/youtube-api-opsaetning.md først.)
  2. Menuen ☰ → Google Auth Platform → Clients → Create client.
  3. Application type: Web application. Name: Badmintonapp server.
  4. Under Authorized redirect URIs → Add URI, indsæt præcis denne adresse:
  5. Tryk Create. Google viser nu Client ID og Client secret — kopiér begge herned og tryk Gem. Secret'en vises kun den ene gang; er den væk, så åbn klienten under Clients og vælg Add secret. En ny klient kan være 5–10 minutter om at virke hos Google.
