# Landeflag

SVG-flag fra [hampusborgos/country-flags](https://github.com/hampusborgos/country-flags)
(public domain), commit `c09927e63705529bbf59ca6684cd9b23225dddad`.

Filnavnet er landets ISO 3166-1 alpha-2-kode (fx `dk.svg`). `utils/flagSeed.js`
seeder dem i `football_logos` ved første opstart.
